# Customer Churn Intelligence Platform

A web-based machine learning platform that predicts whether a telecom customer is likely to churn, returns churn probability, highlights key churn factors, and categorizes the customer into Low, Medium, or High risk.

## Tech Stack
- Frontend: React
- Backend: FastAPI
- Machine Learning: scikit-learn

## Project Structure
- frontend/ -> web UI
- backend/ -> API and backend logic
- ml/ -> datasets, notebooks, training scripts, artifacts
- docs/ -> architecture and project notes
